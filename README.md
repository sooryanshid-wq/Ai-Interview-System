# AI Interview System

## About the Project

AI Interview System is a web-based application designed to help students and job seekers prepare for interviews.

Users can upload their resumes and practice interview questions with the goal of improving their interview skills.

## Features

- User Login Interface
- Resume Upload (PDF)
- Interview Preference Selection
- Simple and User-Friendly Interface
- AI-Powered Interview Preparation (Planned)

## Technologies Used

- HTML
- CSS
- JavaScript

## How to Run the Project

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Run `index.html` using the Live Server extension.
4. Explore the application in your browser.
